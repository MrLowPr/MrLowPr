## 📌 Pinned project — Overdrive

[![Overdrive banner](assets/banner.svg)](https://github.com/MrLowPr/overdrive)

**A PS5 game store with 1,800+ titles, rebuilt from its own binary.**

- Recovered a closed binary and reconstructed readable source from the bundle, then rebuilt the app as modern React + esbuild.
- Browse, search, queue downloads, install and update games entirely from the console UI — no browser round-trip.
- 15 interface languages, RTL-aware layout, controller-first focus navigation.
- Owns the [fork](https://github.com/MrLowPr/overdrive/blob/main/FORK-NOTES.md) of [MyLuxy/overdrive](https://github.com/MyLuxy/overdrive), with documented deltas and a clean upstream merge path.

Repo: **github.com/MrLowPr/overdrive** · Tech: React, JavaScript, C++, esbuild, i18n · License: MIT
